# Top navigation + mobile menu

Desktop: plain-text name left (Nunito 800 — no logo), five section links, then language switcher, night toggle and a small primary **Book a consultation**. Below 1024px the links collapse into **☰ Menu**; the language switcher and night toggle move to a slim utility bar above the header so they stay visible. The menu opens as a flat sheet (`surface`, `radius-lg`, `shadow-sheet`) with the links as big 56px rows and Book + Message at the bottom.
