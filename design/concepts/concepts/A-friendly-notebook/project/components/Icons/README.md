# Icons

Emoji, set in the system emoji font. Rules: one emoji per item, always next to words (never alone as a button label except the icon-only night toggle, which has an `aria-label`); always `aria-hidden`; sizes 18 / 22 / 36 / 44px only; no emoji in headlines. Twelve are allowed — the six core plus six extras shown here. Messaging-app logos are not emoji: use the official marks.
