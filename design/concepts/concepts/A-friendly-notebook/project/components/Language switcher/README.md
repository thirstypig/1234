# Language switcher

EN / 简体 / 繁體 as three plain text links, always visible at the top of every page (in the header on desktop, in the utility bar above the header on mobile), and repeated in the footer. Each link goes to that language's own page (`hreflang`), never a translate widget. Current language: `text-primary` with a 3px `primary` underline and `aria-current="page"`. Tap targets are 44×44px minimum.
